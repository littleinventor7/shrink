# simple ping pong game
This is a simple ping-pong game.

## How to use it
Player 1 uses the W key for up and the S key for down
Player 2 uses the Up arrow key for up  and the Down arrow key for down

## how it works
Each player should try to score more than the other player by preventing the ball from hitting your own wall and trying to make it hit the opponent's wall. 

## building
```
npm install
node build.mjs
```
